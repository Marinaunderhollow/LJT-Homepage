# LJT-Homepage

Personal academic homepage of **Junteng Liu**, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and hosted on GitHub Pages.

## Content

- **About** (`_pages/about.md`): personal details, education, research experience, publications, skills, and contact information.
- **Publications** (`_publications/`): publication entries rendered on the publications page and listed on the about page.

## Running locally

1. Install Ruby, bundler, and nodejs.
2. Run `bundle install` to install ruby dependencies.
3. Run `bundle exec jekyll serve -l -H localhost` and open http://localhost:4000.
